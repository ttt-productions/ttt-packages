# `docs/work/do-later/`

Decided work that is parked until its trigger fires. Nothing here is done now unless DJ pulls it in;
everything here is still real work, kept so it is never lost. This README is shared by every repo;
each repo's `docs/work/do-later/` follows it.

- **In:** DJ decides an item is real but not for now. It names its trigger — the concrete event that
  makes it real work. Most items here are trigger-based, not date-based.
- **Out:** when the trigger fires and DJ pulls it in, it moves to `docs/work/waiting-to-be-implemented/`
  or into a project's step. When an item ships, its description folds into the owning design doc and
  the file is deleted.

Items sit in domain sub-folders so related parked work is found together. A multi-file design that is
one item (a whole folder) keeps its folder. This README never lists what is here — the folder is the
list. The item header is the one format in `<DEV_STANDARDS>/work/README.md`.
