# Adopt @ttt-productions/repo-guards 0.1.17

**What:** Five new guards (four required for every app), a `sharedSource` root, and `documentDrift` may be absent.
**Severity:** high
**Came from:** the ttt-packages shared-standards run (Phase 3 package batch)

- **Package and version:** `@ttt-productions/repo-guards` 0.1.17.
- **Release:** `./scripts/release-multiple.sh dev-standards firebase-helpers repo-guards query-core chat-schemas report-core notification-core ttt-core upload-ui chat-core chat-react patch`.
- **What changed:** New required generic guards (`absentWhen: false` — the guard config refuses to run until each is wired): `mutationOwner` (no raw TanStack `useMutation` outside the app's owner import, including whole-module re-exports and run-time loads), `appRouteOwner` (RULE-STD-ARCH-102: a string or template literal under one of the app's page roots, anywhere outside the app's route owner, fails),`readStateBranches` (RULE-STD-FRONTEND-206: a failure branch that replaces a read also checks that nothing answered; a surface that renders a read's loading state also renders its failure), and `sharedTruncation` (RULE-STD-FRONTEND-007: per-site `truncate` / `line-clamp-*` / `text-ellipsis` and stylesheet clamps outside the shared class's owners fail). New `adminActionSurface` (RULE-STD-FRONTEND-111), facts or `{ absent: why }`. `documentDrift` accepts `{ absent: why }`. New optional root role `sharedSource` (a private source folder the app and its Functions both build from): every scope that reads the app or Functions root reads it too. The Firestore-write analyzer follows a local function that parses and then builds a path. `callableDoubleSurface` also recognizes query-core's `useSessionMutation`. The root exports `rawMutations(file)`, the raw-`useMutation` detector.
- **What the app must change:** Install `@ttt-productions/repo-guards@latest`. Wire `mutationOwner`, `appRouteOwner` (its owner is the app-data package's route builders; framework route files are reviewed exceptions), `readStateBranches`, `sharedTruncation`, and `adminActionSurface` (or `{ absent: why }`) in the guard config; the facts shapes are in `docs/packages/repo-guards.md` § Facts. Declare `sharedSource` in the layout if the app has such a folder, and set `documentDrift: { absent: why }` if the app keeps no document identical across repositories. Fix each first-run finding or add it as a reviewed entry with its reason.
- **Done when:** The lockfiles name `@ttt-productions/repo-guards` 0.1.17 or later, the guard suite runs green with every new guard wired, and the gate is green.
