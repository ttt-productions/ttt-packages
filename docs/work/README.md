# `docs/work/` — ttt-packages

This folder follows the shared `docs/work/` rules in
[`packages/dev-standards/work/README.md`](../../packages/dev-standards/work/README.md): the folders,
the item format, and who reads and writes here. ttt-packages adds `adoptions/<app>/` — one folder
per consuming app (`ttt-prod`, `q-sports`), each file one released package version that app still has
to adopt.
