# Adopt @ttt-productions/ttt-core 0.79.110

**What:** BREAKING: title snapshots leave stored payloads and notifications; new id, route, and copy owners.
**Severity:** high
**Came from:** the ttt-packages shared-standards run (Phase 3 package batch)

- **Package and version:** `@ttt-productions/ttt-core` 0.79.110.
- **Release:** `./scripts/release-multiple.sh dev-standards firebase-helpers repo-guards query-core chat-schemas report-core notification-core ttt-core upload-ui chat-core chat-react patch`.
- **What changed:** Added: `parseAuditionEntryMediaOwnerId`, `nciiDurableCaseId`, `APP_ROUTES` (one builder for every app page, with typed query parameters for the admin view, the Backstage Guide topic, the Hall browse state, the Hall item's sub-item, take-it-down, landing replay, and the payment session), the Hall browse owner (`HallBrowseState`, `HALL_BROWSE_DEFAULTS`, `HALL_LIBRARY_QUERY_KEYS`, `parseHallBrowseState`, `hallBrowseQueryEntries`) and `TakeItDownInAppTarget` (`./paths`); `ADMIN_VIEWS` / `AdminView` and `BACKSTAGE_GUIDE_TOPIC_IDS` / `BackstageGuideTopicId` (`./constants`); `firstSubmissionId` and `intakeActionId` (`./safety`); `contentPublishedStoredCopy` and `contentPublishedNotificationCopy` (`./notifications`); an optional `previousAuditionEntryId` on `audition.entryCreated`. Removed: `MAX_CRAFT_SKILL_NAME_LENGTH`; `craftSkillName` from the invite source and `CraftSkillReference`; `ownedWorkProjects` and `associatedWorkProjects` from `FullUser`; the Square payload's Work, Realm, Hall-item, and craft-skill names (`workRealmTitle` becomes `workRealmIsPublic`); `workTitle` and `hallItemTitle` from the two content-published notification types, which gain a required `hallSubItemId`; `bodyNonArtisanFinal`. The site-tour copy changed.
- **What the app must change:** Install `@ttt-productions/ttt-core@latest` wherever it is declared, then: replace the app's local compound-id parse, durable-case-id, and intake-id copies with the new owners; build every app route from `APP_ROUTES`, each runtime joining its own origin once, and delete the app's own copies of the admin view list, the guide topic ids, and the Hall browse encoder and parser; stop writing every dropped field (the invite source's skill name, the profile's Works lists, the Square payload's names, the two content-published notifications' titles), and pass `hallSubItemId` and `workRealmIsPublic` where the new shapes need them; make the Square published post name no title; render the two content-published notifications through notification-core's `renderContent` with `contentPublishedNotificationCopy` and titles the app resolves at render (a Hall sub-item lookup added beside the existing public lookups); emit `previousAuditionEntryId` where an entry replaces an earlier one; and update the site tour for the removed `bodyNonArtisanFinal`.
- **Done when:** The lockfiles name `@ttt-productions/ttt-core` 0.79.110 or later, every importer follows the new shapes, and the gate is green.
